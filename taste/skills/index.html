      Questions before you install
      
      
      
        
      
          
      Full skill or focused ones?
      
          
      Install the full skill for new screens. Add a focused one, like taste-motion, when you fix one thing per pass: type scale, then cards, then hierarchy, then CTA, then motion.
      
        
      
        
      
          
      Where do the rules come from?
      
          
      From 35 sources, S1 to S35, mostly Instagram reels and posts. Each file lists the sources it uses, with the reel link when one was saved. See every source.
      
        
      
        
      
          
      What does the AI do with it?
      
          
      It picks 2 base colors, 1 accent and 1 type scale, builds, runs the 29-item Slop Check, fixes every hit, then reports each change as rule, before, after.
      
        
      
        
      
          
      How do I update it?
      
          
      Run the same command again. It overwrites the file with the latest version from this site.
