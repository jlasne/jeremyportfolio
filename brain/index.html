/brain

A folder that gets smarter every time you feed it.

Drop articles, transcripts, studies. It stores each one once, files it where it belongs, and rewrites what it knows instead of piling up quotes. Ask it a question, get a position with evidence and dates.

One skill file. One setup conversation. Plain markdown. Works with Claude Code and Claude.ai.
