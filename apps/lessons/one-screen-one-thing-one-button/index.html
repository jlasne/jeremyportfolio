One screen, one thing, one button

A lost user closes your app. They open it, see 6 things at once, and leave before they find the one that matters. Users are bad at telling you how much a screen slows them down, so the fix has to come from you, screen by screen.

Here is how I clean mine.

1. One object per screen.

Every screen shows one thing. One photo, one number, one question or one exercise, sitting in the middle. If a screen needs 2 objects, it needs 2 screens, and the user swipes from one to the next with their eyes on one spot.

2. One button per screen.

One screen, one call to action. Next, Start, Save or Buy: pick the one the user came for. Settings, share and the rest move to a menu or a later screen, so the main button is the only thing the thumb finds in the first second.

The best apps pass the 3-second test. Someone sees the product and, within 3 seconds, thinks they need it.

3. Give it space.

Space makes a screen easy to read. On an onboarding screen, 5 words is enough: think of a TikTok caption. If the user has to read a line twice, the text is too long or too tight, so cut words before you shrink the font.

4. Remove every legend.

Every legend can go. Labels under icons, captions on charts, hints next to fields: each one explains something the screen should make clear on its own. If a screen needs a legend to make sense, redesign the screen.

5. Nothing more.

Then ask one question. For each thing left on the screen: does the user need it to take the next step? If the answer is no, cut it, and repeat until the screen holds one object, one button and nothing else for the eye to chase.

Timeleft shows how far it goes. The dinner app seats 5 strangers at one table, with no bios, no swiping and no planning.

One screen, one thing, one button. Nothing more on it.
