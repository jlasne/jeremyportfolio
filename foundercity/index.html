Make a read-only key

  1. Open RevenueCat, then Project settings → API keys.
  2. Click + New API key, name it Founder City, version V2.
  3. Set every permission group to No access, then Charts metrics permissions to Read.
  4. Click Generate and copy the key once.
That key reads 6 numbers: active users, trials, subscriptions, MRR, revenue, new customers. It reads no emails, names, customer IDs or purchases, and it writes nothing.
