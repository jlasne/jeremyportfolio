Make a read-only key

  1. Open RevenueCat, then Project settings → API keys.
  2. Click + New API key and name it King of Founders.
  3. Set API version to V2.
  4. Set every permission group to No access.
  5. Open Charts metrics permissions and set it to Read.
  6. Click Generate, then copy the key once. RevenueCat shows it a single time.
That key reads 6 numbers: active users, active trials, active subscriptions, MRR, revenue and new customers. It cannot read emails, names, customer IDs or purchases, and it cannot write anything.

Staying anonymous

🎭 Hide the handle and your kings walk without a name. 🏰 Hide the app and the kingdom takes a name drawn from its own seed. The numbers still count toward the leaderboard either way.

The land

Land radius is the square root of the population. Any town that reaches the sea builds a harbour. Nothing is built on bare rock or a steep slope. The world grows as the total population grows, and land already drawn never moves.

Refreshed once a day. Active Users lags 1 to 2 hours.
